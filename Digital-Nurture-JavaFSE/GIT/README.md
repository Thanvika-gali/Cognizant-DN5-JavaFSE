# Overview

Git is a distributed version control system that enables developers to efficiently manage source code, collaborate with teams, maintain project history, and safely track software changes.

These hands-on exercises were completed as part of the **Cognizant Digital Nurture 5.0 Program**, providing practical experience with Git commands, branching strategies, merge conflict resolution, repository synchronization, and GitHub integration.

The exercises focus on real-world Git workflows commonly used in software development environments.
