# 🎓 Student Course Portal

A modern Angular 20 web application developed as part of the **Cognizant Digital Nurture 5.0 – Angular Hands-On** program.

The application allows students to browse available courses, view detailed information, enroll in courses, manage enrollments, and perform CRUD operations using a mock REST API powered by JSON Server.

---

## 🚀 Features

- Dashboard with course statistics
- Course Listing
- Course Details Page
- Student Profile
- Enrollment Form
- Search Courses
- Add Course
- Edit Course
- Delete Course
- Route Guards
- Routing with Lazy Loading
- JSON Server Integration
- HTTP Client CRUD Operations
- Custom Pipes
- Custom Directives
- Angular Services & Dependency Injection
- Responsive UI

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/<your-username>/<repo-name>.git
```

Navigate to the project

```bash
cd student-course-portal
```

Install dependencies

```bash
npm install
```

Start Angular

```bash
ng serve
```

Start JSON Server

```bash
json-server --watch db.json
```

Open

```
http://localhost:4200
```
